TURN 1 Tarantuverse analytics · web + mobile · 2026-10-26

One Analytics page, built for three animals

The median keeper has three animals, so the page leads with sentences a small collection can answer (who is due, who molted last, the longest gap since a meal) and keeps distributions for the nine keepers with more than fifteen. Premium lives on the same page as a blurred preview of the keeper's own data. Sections: 1a recommendation + entry points · 1b the page in four theme combos · 1c every state · 1d web · 1e two-page variant for comparison · 1f chart grammar.

1a

Recommendation and entry points

§6 decisions, then how people get there
6.1 PAGES One page. Premium inline.

Sex split, species and paid total were on both pages. One page removes the overlap, and a free keeper sees Premium every time they open analytics instead of behind a button nobody finds. The two-page version is in 1e for comparison.

6.2 NAVIGATION An Insights card on Home, a row in You, a sidebar row on web.

No new tab: the five-tab spine from the redesign handoff stays. The Home card rotates to whatever changed most recently, computed from recent_activity[0], which the Home already fetches. It gives analytics a reason to be opened, not just a place to be found.

6.3 CARDS Keep 6, merge 4, drop 3.

New first row: Right now (due, last molt, longest gap). Keep Collection, Feeding, Molts, Recent activity, Premium set. Notable Animals merges into Molts; Top Species merges into Collection and only expands past 5 species; Total Activity, Average Price and Species Diversity go. Breeding is not on the page.

6.4 CHARTS One grammar, three shapes, both platforms.

Bars, a line, and a segmented bar. Mobile moves to react-native-svg (already in the binary); web keeps recharts but styled to the same spec in 1f. No axes grid, no legends that repeat the labels, every chart has a 0 / 1 / many rule.

1f

Chart grammar

three shapes, one palette, the 0 / 1 / many rule
BARS · MONTHLY COUNTS
Bar primary, max bar secondary with its value printed above. Zero months are a 2px border stub, not nothing. Month initials in textTertiary 9–10px. No y-axis, no gridlines.
0: no chart, one sentence. 1: chart with one bar and the sentence names the month. many: as shown.
LINE · RUNNING TOTAL
2.5px primary stroke, 14% fill beneath, end dot r4 with a surface-coloured ring. First and last values printed; nothing else. Step rendering (counts only change on an event).
0: impossible (there is always ≥1 point once an animal exists). 1: a dot on a flat track with the month under it. flat: straight line, sentence says "No change since".
SEGMENTED BAR · A SPLIT
1 male 3 female 2 unsexed
Replaces every pie. 8px tall, 2px gaps, radius 4. Legend is glyph + count + word, so colour is never the only carrier. Sex uses the fixed male / female / textTertiary; enclosure and taxon splits use primary, #8b5cf6, success, warning in order.
1 segment: no bar, sentence ("1 terrestrial. A split appears with two or more animals.").

Horizontal bars scaled to the max row. Label column 64 (mobile) / 70 (web), ellipsised. Rows with 0 keep their track and say "none yet". Show all rows ≤ 5; otherwise top 3 (animals) or top 5 (species) plus an "n more →" link to a sorted list screen.
