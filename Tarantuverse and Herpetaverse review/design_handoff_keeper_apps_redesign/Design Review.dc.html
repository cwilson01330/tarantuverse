Design review

Tarantuverse & Herpetoverse

Two sibling keeper apps built from one codebase that have quietly drifted apart. Below: every screen recreated from source, next to a proposed revision. The brief was flow, consistency, and surfacing what's already there — so the recommendations are almost entirely about hierarchy and discoverability, not repaint. The gradient stays.

Feeding is the weekly job Photos are the point Density 7/10 Emoji → MDI icon set Keep the gradient

Seven findings

01Nine features are unreachable

In Tarantuverse's tab layout, Search, Enclosures, Forums, Species and Scorpions are all declared href: null — routable but invisible. Analytics, Breeding, Feeders and Import only exist inside a Quick Actions grid at the very bottom of the dashboard. This is the discoverability problem you described.

02Feeding is buried under stats

The job users do weekly sits fifth on the page: four equal-weight stat tiles, then the Feeding Day button, then the alert list. "Needs Feeding" and "Feeding Alerts" are the same data rendered twice, 400px apart.

03Photos are treated as thumbnails

Tarantuverse grid cards give the photo 150px and then cover its four corners with badges — the premolt badge and the taxon glyph both claim bottom-left. Herpetoverse rows give the photo 56px. For a hobby that's this visual, the animal should be the largest thing on screen.

04The two apps have drifted

Herpetoverse's dashboard is a port of Tarantuverse's, but the values slid: stat icon 40 vs 36px, stat value 24 vs 26px, section title 18 vs 17px, alert thumb 40 vs 42px, feed row radius 12 vs theme. Tarantuverse renders emoji inside its stat icon boxes; Herpetoverse renders MDI icons in the same slot.

05Emoji are doing icon work

🕷️ 🦋 🔮 🍽️ 📊 👥 ✅ appear as section markers, stat glyphs, filter chips and placeholder art. They render differently per OS, can't take a theme color, and can't be sized on the 4pt grid. Both apps already depend on MaterialCommunityIcons — the set is right there.

06Herpetoverse has no light mode

Tarantuverse ships createLightColors() plus eleven species themes and two density presets. Herpetoverse exports a single hardcoded darkTheme object. Same context shape — porting the light branch is a small, high-value change.

07Tool actions hide in 22px header icons

Herpetoverse's collection header stacks four unlabeled 22px glyphs — bell, freezer, import, fork. Two of them (Feeders, Feeding Day) are core weekly flows. Nothing tells a new keeper the freezer icon is an inventory system.

Feeding becomes the page, not a tile

"Needs Feeding" and "Feeding Alerts" merge into one card: count, taxa breakdown, Start button, and the three most-overdue animals with a one-tap check-off. Everything the weekly loop needs, above the fold, no scroll.

"31 days" → "17d overdue"

The server already computes a species- and life-stage-aware is_overdue. Show the delta, not the raw day count — 31 days means nothing without knowing the target for that species.

Vanity stats shrink, tools appear

Total Molts and Premolt Alerts are reference numbers, not actions — they drop to a compact three-up strip and gain Feeder stock, which currently has no dashboard presence at all. The space buys an eight-tile "Everything else" grid that surfaces Enclosures, Forums and Import for the first time.

Header carries the count

"62 animals · 18 species" as a header subtitle retires the My Collection tile entirely — and matches Herpetoverse's existing capSubtitle pattern, so the two apps converge on one header. Search returns to the header where users look for it.

Five tabs, shared with Herpetoverse

Home · Collection · Species · Community · You. Species stops being an href: null orphan, and both apps run the same spine with one swapped slot (Community here, Breeding there).

One screen of chrome before one animal

Premolt banner, search, taxon chips, sort chips, title + view toggle, stats card — six stacked bands, roughly 430px, before the first card. On a 62-animal collection the keeper scrolls past all of it every single time. Search and filters move into the header; sort joins the filter row as an icon; the stats card is deleted (it duplicates the dashboard).

Filter chips carry counts

Today all eleven taxon chips render whether or not the keeper owns any — Herpetoverse already solved this with ownedTaxa. Port that, add counts, and lead with a "Due 7" filter so the collection screen answers the feeding question too.

Four corner badges → one status line

Today the feeding pill, sex badge, premolt badge and taxon glyph all overlay a 150px photo — and premolt and taxon are both positioned bottom-left, so they collide. Proposed: photo goes 4:5 and only sex (and premolt, when active) overlay it; feeding status becomes a dot + label in the card footer where it can be read at a glance and colored by theme.

Name first, species second, stop repeating

The current card prints common name in the title and again on the third line — "Brazilian Red and White Tarantula" twice, four lines tall. Keeper name → scientific name, two lines, always.

Bug caught in your own store screenshot

The second card in app_screens/01.png reads "✓ nulld ago" — a null day count string-concatenated into the badge. Guard for never-fed and render "Not yet fed".

Same skeleton as Tarantuverse

Feeding hero → three-up stat strip → tools grid → tab bar, identical structure and identical spacing values. The apps stay distinct through color and iconography, not through layout divergence — which is what makes them feel like separate products today.

A gradient of its own

Tarantuverse gets electric blue → neon pink; Herpetoverse gets a deep emerald fade into the background. Quieter, because reptile keeping reads calmer, but unmistakably the same family. layout.useGradient is already in the HV theme, just unused.

Two Quick Actions is not a grid

The current five-tile grid duplicates Add and Feeding Day, both already elsewhere on the page. Meanwhile the morph calculator, QR photo upload, weigh-in and shed logging — real, shipped features — have no home. The eight-tile surface is where they go.

Make the free-tier cap legible

"3 / 5 animals" currently appears twice as 11–12px grey — as the header subtitle and again in the stat card footer. Once in the header, plus one honest upgrade row at the bottom of the page where it isn't blocking the feeding job.

Ship light mode

Herpetoverse's ThemeContext exports one frozen dark object. Tarantuverse's has the whole light branch, plus eleven species palettes and the Keeper/Hobbyist density presets. Porting that context wholesale gets Herpetoverse light mode, theming and density in one change — and puts both apps on one theme API.

Four unlabeled header glyphs → one

Bell, freezer, tray, fork at 22px with no labels. Feeders and Feeding Day move to the labeled tools grid on Home; Import moves into the add flow; the bell stays. Search, filter and layout take the header instead — the three things a list screen actually needs.

The right-side indicator stack is misaligned

Sex chip, day pill and Fed button sit in one row, but the Fed chip carries marginTop: 6 inside an alignItems: center row, so it hangs low against its siblings. It's visible in the shipped build.

"11d" doesn't say overdue

The pill colour encodes urgency but the number doesn't, and colour alone fails for colour-blind keepers. Same fix as Tarantuverse: state the delta in words, keep the colour as reinforcement.

Quick actions on the card, not in a long-press

Mark fed, log shed and log weight already exist in AnimalActionSheet — behind a long press that nothing advertises. Surfacing them as a three-button row on each card makes the whole husbandry loop one tap, and is the single biggest discoverability win in this app. The card knows when an animal is CGD-fed, so the primary button relabels itself to "Refresh CGD".

Morph belongs on the card

For breeders, "Pastel het Clown" is the identity — more so than the scientific name. It's already in the genotype data; append it to the species line.

1
Feeding hero on both Home screens
One card, no new data. Fixes the weekly loop and removes a duplicate section.

Tools grid + five-tab spine
Every orphaned route gets a labeled entry point. This is the discoverability fix.
3
Card rework in both collections
Bigger photos, one status line, on-card actions. Also kills the "nulld ago" bug.

Emoji sweep + shared tokens package
Mechanical, low-risk, and stops the two apps drifting again.

Light mode, species palettes and density presets in one move.
