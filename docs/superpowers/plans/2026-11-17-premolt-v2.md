# Premolt v2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Premolt prediction for every predator taxon, with a fasting signal measured against each animal's own usual gap, keeper answers ("Yes, pause feeding" / "Not yet") on the card, a daily record of prediction episodes, and a read-only hit-rate report.

**Architecture:** `services/premolt_service.py` stays the one rule, moved from the legacy `Tarantula` row to `Invert`; pure helpers compute the fasting signal and eligibility. A once-a-day pass riding on the existing digest cron writes `premolt_episodes`; an answer route sets the existing feeding pause or a 14-day snooze. Server builds the reason sentence and a `show_alert` flag so both clients render from one source through a small shared view lib.

**Tech Stack:** FastAPI + SQLAlchemy + Alembic + pytest (apps/api); Next.js 14 + Tailwind (apps/web); Expo Router + RN + jest-expo (apps/mobile).

**Spec:** `docs/superpowers/specs/2026-11-17-premolt-v2-design.md` (read it first).

## Global Constraints

- TV only. Herpetoverse, colonies and sitter cards are unchanged (sitter keeps its tarantula-only boolean: `routers/sitter_passes.py::_premolt_likely`, `services/sitter_card.py::PREDATOR_TAXA_WITH_PREMOLT`).
- Eligible = active invert (no `died_at`, no `transferred_out_at`), `utils/feeding_mode.has_feeding_cadence(taxon, species)` true, and not matured. Matured = an `is_ultimate` molt, OR `life_stage == 'adult'` for a taxon not in `ADULTS_KEEP_MOLTING = ("tarantula", "centipede", "whip_spider", "other")`. No stage + no ultimate molt = eligible.
- Fasting thresholds: `FAST_MULTIPLIER = 2.5`, `FAST_MIN_DAYS = 14`, `USUAL_GAP_WINDOW_DAYS = 180`, `USUAL_GAP_MIN_MEALS = 4`, `STILL_LOGGING_DAYS = 7`, `SNOOZE_DAYS = 14`, `HIT_WINDOW_DAYS = 45`, `STALE_YES_DAYS = 120`, `RULE_VERSION = "2026-11-v2"`. Existing branch thresholds unchanged.
- Fallback usual gap = `routers/inverts.py::_recommended_feeding_interval_with_source(life_stage, species, inv.feeding_interval_days, taxon=inv.taxon)[0]` (import lazily — circular import, same as `feeding_status.compute_feeding_status`).
- "Today"/day counts use the OWNER's `notification_preferences.tz_offset_minutes` (None = UTC) via `utils/feeding_pause.today_for_offset` and the `_local_date` convention.
- Still-logging guard = a `FeedingLog` with `created_at` in the last 7 days on any of the owner's `inverts` (any author). HV doesn't count.
- Answer route: `POST /api/v1/premolt/inverts/{invert_id}/answer` body `{"answer": "yes" | "not_yet"}`, `@policy("keeper")` + `load_invert(..., "keeper")` + `refuse_if_closed_invert`. yes → `feeding_paused_reason="premolt"`, `feeding_paused_until=None`, then `mirror_invert_update_to_legacy`. not_yet → `inverts.premolt_snoozed_until = today + 14`.
- Response compatibility: keep every existing `PremoltPrediction` field (incl. `tarantula_id`, `tarantula_name`) and `PremoltSummary.total_tarantulas` so old app versions keep working; add the new ones.
- Copy (exact): headline "May be in premolt"; buttons "Yes, pause feeding" / "Not yet"; after Not yet "Hidden for 2 weeks"; paused state "Paused · premolt"; clear state "No premolt signs". "may be", never "is"; no emoji, no countdown in new copy.
- Privacy: episodes/answers only in the owner's own export; never on public routes, share cards, card links, keeper profiles, care sheets, transfers.
- Repo rules: no git writes by agents ("commit" = controller snapshot); API tests via `with-pg.sh`; JS checks in the mirror after `js-sync.sh`; never install into the repo; web dark mode on every element; mobile theme tokens only, token gate passes without re-baselining; no new native modules.

## Review Focus

1. A tarantula that molted 5 days ago and has not been fed since must NOT be flagged by the fasting branch — Task 2 `test_fasting_respects_post_molt_window`.
2. A keeper who stopped using the app (no feedings logged anywhere for 8+ days) must not see every animal flagged — Task 2 `test_fasting_needs_keeper_still_logging`.
3. "Not yet" must keep the alert away for 14 days even if the signal keeps firing, and the daily pass must not reopen an episode during the snooze — Task 3 `test_not_yet_snoozes_and_pass_does_not_reopen`.
4. An old app version calling `/premolt/dashboard` and `/premolt/tarantulas/{id}/prediction` must get valid responses for a collection that now includes jumpers (old fields present) — Task 2 `test_old_routes_keep_old_fields`.
5. The daily pass must never break the digest: an exception inside it is logged and the digest result still returns — Task 3 `test_episode_pass_failure_does_not_break_digest`.
